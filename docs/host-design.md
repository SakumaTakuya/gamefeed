# A. 規約

## A.1 見立て

ラン画面を、**上で綴じた計算ドリル**に見立てる。1 回のランが 1 冊、1 つの手番が 1 ページ。

| ランの言葉（`run.md`） | 画面での見え方 |
| --- | --- |
| 固定ヘッダー | 綴じ目（製本テープ）。動かない |
| ランの開始前 | 表紙 |
| 幕間（1.0 秒） | 次の問題のページ。前のページをめくって出す |
| 手番 `t`（0 始まり） | 「第 `t + 1` 問」 |
| 結果フラッシュ（0.5 秒） | 赤ペンの採点。ゲームの最後の画面の上に描く |
| 残機 | 綴じ目の右の丸 3 つ |
| 終了 | 「おわり」の判子 |
| 成績表 | 最後のページ |

ゲームそのもの（iframe の中）には手を加えない。ゲームの絵は投稿ごとに違ってよく（`game-contract.md` A.14）、Host の絵だけを 1 つに揃える。

## A.2 色と書体

| 役 | 値 |
| --- | --- |
| 紙 | `#f7f3e6` |
| 紙の裏（めくれた面） | `#ece5d2` |
| 方眼の線 | `#cfdcf0` |
| インク（文字） | `#1d2b4f` |
| 赤ペン（採点、ミス、残機、判子） | `#d8352a` |
| 見出しの青（「第 n 問」、表紙） | `#2b6fd6` |
| 綴じ目のテープ | `#1f3d7a` |
| 表紙の差し色 | `#ffd84d` |

- 見出し（「第 n 問」、綴じ目の文字、表紙）は丸ゴシックの太字（Zen Maru Gothic 900）。本文（動詞、点数、成績表）は教科書体（Klee One 600）
- 書体はアプリのオリジンから配る（`security.md` A.6 の CSP の内側）。読み込めるまでは端末の書体で出し、**書体の読み込みでランの進行を待たせない**
- 赤は「採点する側が書き込んだもの」にだけ使う: 採点の点数と印、「ミス」、残機の丸、判子（「おわり」と成績表の判子。A.8）。ボタンや飾りに使わない
- 大きさは舞台（9:16 の枠）の幅に対する比で決める。画面の幅で絵の比率が変わらないようにする

## A.3 綴じ目（ヘッダー）

- 舞台の上に固定する。めくりの間も動かない。めくられる紙は、綴じ目の下の辺を軸にして消える（A.7）
- テープの色の地に、下の辺に沿ってミシン目（破線）を 1 本
- 左に「第 n 問」。中央に周回（2 周目から「k 周目」。`run.md` A.8）。右に残機の丸 3 つ（残っている数だけ赤く塗る。エンドレスだけ）
- ランの外（表紙、成績表）では、左に「GameFeed」、中央にランの種類（「エンドレス」）
- 文字は白。残機の丸は白い縁

## A.4 表紙

- 青い表紙。白い題字の札に「GameFeed」、差し色の帯に「エンドレス ドリル　ぜんぶで 50 問」（上限の手番数。`run.md` A.2）、ボタンは「はじめる」
- 「はじめる」で表紙をめくり（A.7）、第 1 問のページを出す。ここからの進行は `run.md` A.5 の 4 と同じ

## A.5 問題のページ（幕間）

`run.md` A.5 の 4 で描く。内容は次の手番の動詞と入力（`ready` の `verb` / `input`）で、Host が足すのは飾りだけ。

- 方眼の紙。中央に上から、青い丸見出し「第 n 問」、動詞（いちばん大きく）、入力のアイコンと名前（「タップ」「長押し」「スワイプ」「ドラッグ」）、2 周目からは「k 周目」
- 右上に得点欄（空の枠と「点」）、下にページ番号（「— n —」）。どちらも飾りで、値を入れない
- 動詞と入力は紙の中央に置く。めくり（A.7）は右下から始まるので、中央はめくりの半ばで見え始める
- 「新作」を知らせない（`run.md` B.6）
- 幕間の終わりにページの文字を消して、下のゲームを見せる。消し方は瞬時（暫定。未解決）

## A.6 採点（結果フラッシュ）

`run.md` A.5 の 2 で描く。ゲームの最後の画面の上に、紙の色の幕（不透明度 0.88）を掛け、赤ペンで点数と印を描く。

| 印 | 条件 | いつ決まるか |
| --- | --- | --- |
| ✕ | ミス（`score < miss_below`。`run.md` A.7） | `end` の瞬間。通信を待たない |
| 花丸 | ミスでなく、応答の偏差値が 60 以上 | 応答が届いたとき |
| ○ | ミスでなく、応答の偏差値が 50 以上 60 未満 | 同じ |
| △ | ミスでなく、応答の偏差値が 50 未満 | 同じ |
| 印なし | 校正中・新作枠（`miss_below: null`）、skip、応答がまだ届かない | — |

- 境界は成績表の記号列（`scoring.md` の成績表の節。`◎` / `○` / `△` / `×`）と同じで、暫定。変えるときは両方を変える
- **Host は偏差値を推測しない**。ミスでない手番の印は、応答の `deviation` が届いてから描く。届く前にめくり（A.7）が始まったら、そのページには点数だけが残る。成績表（A.8）には凍結値から印が付く
- ミスの手番は、応答の偏差値が何であっても ✕。ミスでない手番は、応答の偏差値が 40 未満でも △（計画の閾値は作成時の分布で、応答の偏差値はその後の分布で出るので、境界でずれることがある。進行と同じく、凍結した `miss_below` を正とする）
- 点数は大きく、少し傾けて書く。その下に「偏差値 n」（届いたら）。ミスなら「ミス」
- 印は一筆で 0.38 秒（暫定）かけて描く。✕ は 2 画。めくりが始まった時点で、描きかけの印は描き終えた形にする
- skip（`via: timeout / error`）は点数の代わりに「—」

## A.7 めくり

今見えている画面を 1 枚の紙として、右下の角から折り返し、上の綴じ目まで運んで消す。下から次のページが出る。

**いつめくるか**

| めくられる紙 | 下から出るもの | 時点 |
| --- | --- | --- |
| 表紙 | 第 1 問のページ | 「はじめる」 |
| 採点（前のゲームの iframe と、その上の採点の層） | 次の問題のページ | 幕間の始め（`run.md` A.5 の 4） |
| 「おわり」（最後のゲームの iframe と判子） | 成績表 | 成績表を出すとき |
| 成績表 | 第 1 問のページ | 「もう一回」 |

**形**。舞台の幅を `W`、高さを `H`、左上を原点とする。

- 紙の右下の角 `C = (W, H)` を、`P(θ) = (W − 0.5·H·sin θ, H·cos θ)` に運ぶ。`θ` は 0 から π まで
- 折り目は、`C` と `P(θ)` を結ぶ線分の垂直二等分線
- めくられる紙のうち、折り目に対して `C` と反対の側はそのまま見せる（表）。`C` の側は切り落とし、その形を折り目で鏡映しにして紙の裏の色で描く（裏）
- 裏には折り目に沿って陰影を付ける。下から出るページには、折り目に沿って影を落とす
- `θ = π` で折り目は上の辺に重なり、紙全体が綴じ目の上へ返って見えなくなる。舞台の外に出た部分は描かない
- この軌道では、上の辺（綴じ目）は最後まで折れない（`P(θ)` は右上の角から `H` 以内、左上の角から対角線の長さ以内にある）

**時間**

- 0.62 秒（暫定）。進み方は ease-in-out（`θ = π·e(t)`、`e` は 2 次の ease-in-out）
- めくりは幕間の 1.0 秒の**内側**で行う。幕間の長さ、`start` を送る時点、先読みの判定（`run.md` A.5 の 4〜6）を変えない
- めくりの間、めくられる側のゲームはすでに終わっている（`end` の後）。入力を渡さない

**実装の制約**

- めくられる紙は、前のゲームの iframe を含む要素そのもの。画像に写し取らない（配信オリジンの iframe は Host から読めない。`security.md`）。形は要素の切り抜き（`clip-path`）と、裏を表す別の要素の変形で作る
- `run.md` A.5 の 7（旧 N の `destroy` と iframe の取り外し）は `start` の後で、めくりの後になる。順序を変えない
- めくりのために iframe を増やさない（`run.md` A.4 の 3 枚のまま）

**動きを減らす設定**（`prefers-reduced-motion: reduce`）

- めくらない。次のページを 0.15 秒（暫定）で重ねて入れ替える
- 印は描き終えた形で出す
- 設定の有無で、進行の時点（幕間の長さ、`start`）は変わらない

## A.8 おわりと成績表

- ランが終わったら（`run.md` A.5 の 3）、最後のゲームの画面の上に紙の色の幕を掛け、「おわり」の丸い判子を押す（赤、二重の縁、少し傾ける）
- 成績表を出すときにめくり（A.7）、最後のページとして成績表を出す
- 成績表の項目は `run.md` A.11 のとおりで、足しも引きもしない。見え方:
  - 見出し: 青い丸見出しでランの種類、その下に大きく「n 本」（デイリーは平均偏差値）、「総合 偏差値 n」
  - 科目欄: 1 行に、番号、題名（2 周目からは速度）、偏差値、印（A.6 と同じ 4 つ。校正中と skip は「—」）。行は罫線で区切る
  - 総合偏差値に応じた判子を右上に 1 つ: 55 以上「よくできました」、45 以上「がんばりました」、それ未満「もうすこし」（暫定）
  - ボタンは紙の下に。インクの色
- 方眼は敷かない（表が読みにくくなる）。紙の色だけ

## A.9 Host の層とゲームの区別

- Host が描くもの（綴じ目、問題のページ、採点、判子、成績表、めくり）は、すべて iframe の上の層に置く（`security.md`、`run.md` A.5）
- Host の層は必ず「紙」を持つ: 方眼の紙か、紙の色の幕。ゲームの画面にじかに文字だけを載せない。ゲームが似た絵（黒板、切り絵など）を描いても、綴じ目と紙で Host の層だと分かるようにする
- ゲームの上に載せる Host の文字（残り時間の線を除く）は、採点と「おわり」だけ

## A.10 検査する性質

| ID | 性質 |
| --- | --- |
| H1 | 印は「ミスか」と「応答の偏差値」だけから決まる。ミスなら ✕、ミスでなければ 花丸 / ○ / △ のどれか、`miss_below: null`・skip・応答なしは印なし |
| H2 | めくりの形: `t = 0` で紙の全面が表、`0 < t < 1` で上の辺のどの点も裏の側に入らない、`t = 1` で表が残らない |
| H3 | めくりの有無と動きを減らす設定は、`start` を送る時点と幕間の長さを変えない |
| H4 | 問題のページに出る文字は、手番の番号・動詞・入力・周回だけ。新作かどうかで見た目が変わらない |
| H5 | 成績表に出る値は `finish` の凍結値だけ（`run.md` A.11） |

# B. 解説（規則の理由と却下した案）

## B.1 なぜドリルか

2026-11-26〜27 に、同じランを 4 通りの Host の絵（今の絵・答案・チャンネル・黄色）で試作し、オーナーが遊んで選んだ。

- 選ばれたのは「答案」。プロダクトの言葉がもともと偏差値・科目欄・成績表で、Host を「採点する側」にすると言葉と絵が一致する
- オーナーの指示で「計算ドリル。上綴じ」「幕間はページをめくる」に寄せた。ゲームごとに絵が違うこと（`game-contract.md` B.13）と、1 ページ 1 問で次々めくるドリルの形が合う
- 紙の明るい色は、暗い地のゲームが多い中で Host の層を見分けやすくする（A.9）

却下した案:

- **チャンネル**（テレビのチャンネルを替える。砂嵐、太い縁取りのテロップ、カラーバー）。ゲームごとに絵が違うことの見立てとしては良いが、偏差値や成績表の言葉と結び付かない
- **黄色**（黄と黒の 2 色、大きな文字、横からの拭き取り）。今の絵の延長で整っているが、覚えられる顔にならない
- **今の絵**（暗い地に白い文字）。Host の層がゲームに紛れる

## B.2 めくりの形

- 最初の試作は、紙を上の辺を軸に手前へ起こす回転だった（0.46 秒）。オーナーが示した参考（StPageFlip の、角を折り返してめくる動き）のほうが紙らしいので、折り目で切る形に変えた
- **StPageFlip そのものは使わない**。左右綴じ専用で、ページを自分の要素か画像として持つ前提になっている。こちらはめくられる紙が配信オリジンの iframe で、中を読めず、作り直しもできない。折り目で要素を切り抜くだけなら iframe のまま使える
- 折り目はまっすぐな 1 本の線で、紙のしなりは陰影で見せる。曲面にはしない（iframe を曲げられない）
- 角の軌道を楕円弧にしたのは、上の辺が折れない範囲に収めるため。綴じてある辺が折れると、ドリルに見えない

## B.3 印を応答の偏差値で決める理由

花丸・○・△ の境界は偏差値で、偏差値は分布を持つサーバにしか出せない（`run.md` B.2）。

- **取った案**: ✕ だけを `end` の瞬間に決め（すでに `miss_below` がある）、残りは応答が届いたら描く。`run.md` A.5 の 2 の「応答の偏差値は届いたら表示に足す」と同じ扱いで、サーバにも計画にも手を入れない。回線が遅いと印が出ないページができるが、間違った印は出ない
- **却下した案: 50 と 60 の閾値も計画に凍結する**。Host が `end` の瞬間に 4 つとも決められ、成績表とも必ず一致する。ただし計画・記録・DB の列・不変条件（`data-model.md` I12・I13）・`scoring.md` A.6 の検証（S4）を広げることになる。印は表示だけで進行に関わらないので、今はやらない。印が出ないページが目立つようなら見直す
- **却下した案: ミスでなければすぐ ○ を描き、偏差値が届いたら描き足す**。届いた偏差値が 50 未満だと、○ を △ に描き直すことになる

## B.4 動きを減らす設定

めくりは画面の大半が動く。設定がオンの人（オーナー自身がそうだった）には出さない。代わりを「重ねて入れ替える」にしたのは、動きがほぼなく、紙が替わったことだけは伝わるため。却下した案: ページを動かさず、右下に折れた角だけを一瞬見せる（これも動きではあり、実装が 1 つ増える）。
